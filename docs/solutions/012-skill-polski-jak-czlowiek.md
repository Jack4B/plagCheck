# 012 — Skill „polski-jak-czlowiek”

`.claude/skills/polski-jak-czlowiek/SKILL.md` — zasady naturalnego polskiego dla tekstów pisanych
z pomocą AI: czerwona lista fraz AI (ta sama, którą wyłapuje `ai_detector.py`), kalki z angielskiego,
typografia (cudzysłowy „”, półpauza, przecinki), rejestr, opcjonalny koloryt wielkopolski.

Granica: skill poprawia styl; nie dodaje celowych błędów i nie służy do ukrywania pochodzenia
tekstu tam, gdzie wymagana jest samodzielna praca (zgodnie z zasadą projektu: narzędzie do
samokontroli, nie do omijania systemów uczelnianych).
